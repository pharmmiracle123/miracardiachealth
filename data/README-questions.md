# MBBS Progressive Question Bank

## How it works
- **300 Level students** receive questions covering **200L + 300L** scheme of work (Anatomy, Physiology, Biochemistry, Intro Pathology/Pharmacology, Community Medicine foundations, Clinical Skills).
- **400 Level students** receive the above **plus** 400L topics (Systemic Pathology, Haematology, Microbiology, Clinical Pharmacology, Intro Clinical Medicine & Surgery).
- **500 / 600 Level students** receive the full bank covering **200L → 500L** (adds Obstetrics & Gynaecology, Paediatrics, advanced clinical topics).

## Progressive Unlock
After a student scores **≥ 75%** on a set of questions, the next set is unlocked automatically.

## Payment
₦1,000 grants **30 days** of access.  
Payment is **auto-approved** via the Cloud Function / webhook (no manual confirmation required).

## Expanding the bank
Add more questions to `data/mbbs-questions.js` following the same structure, or use the Admin panel to manage courses.
